# CHG-2026-09-09-002：三端设备诊断工作台

## 需求

- IOT-DEVICE-001

## 变更

- React、Vue、Angular 均提供设备概览、影子、时序、原始消息、告警、位置与控制视图。
- 三端统一调用共享 Mock API，并展示时序缺点质量、未定位状态及离线控制失败原因。
- 修正 Vue 与 Angular 原控制入口将离线命令误报为“已接受”的问题。
- 增加三端源码契约测试，锁定诊断方法和关键异常语义。

## 验证

- `npm.cmd test`：根门户及 React、Vue、Angular 构建成功，28 项测试通过。
- `npm.cmd run lint`：通过。

## 已知限制

- 当前为确定性 Mock 数据，控制命令不连接真实设备。
- ECharts 产物仍有超过 500 kB 的构建提示，不影响功能验收。

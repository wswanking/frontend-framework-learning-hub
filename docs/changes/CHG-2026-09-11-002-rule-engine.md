# CHG-2026-09-11-002：规则引擎闭环

## 需求

- IOT-RULE-001

## 变更

- 扩展规则节点、连线、版本、试运行步骤和执行日志领域契约。
- Mock API 支持规则列表、保存校验、启停、逐节点试运行、实时事件消费和日志筛选。
- 保存时校验单触发器、至少一个动作、连线引用和循环依赖，并返回具体环路节点。
- React、Vue、Angular 均实现规则摘要、编排画布、版本备注、环路演示、追踪详情和日志筛选。
- 禁用规则接收实时事件时不创建日志或告警；试运行输出标记为未应用，不改变设备状态。

## 验证

- `npm.cmd test`：根门户与三端构建成功，36 项测试通过。
- `npm.cmd run lint`：通过。

## 已知限制

- 表达式只执行预定义安全条件，不运行用户提供的任意 JavaScript。
- 画布为可读的节点与连线编排视图，不包含自由拖拽布局。

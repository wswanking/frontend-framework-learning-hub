# CHG-2026-09-11-004：OTA 灰度升级生命周期

## 需求

- IOT-OTA-001

## 变更

- 扩展 OTA 任务、批次、设备阶段历史、尝试、操作日志和版本分布契约。
- Mock API 支持创建、开始/继续、按批推进、暂停、取消、失败重试和独立回滚。
- 10% 灰度批次按顺序推进；失败率超过阈值时自动暂停、阻止后续批次并创建告警。
- 重试追加新尝试并保留原失败原因；回滚创建反向任务，不修改原任务历史。
- React、Vue、Angular 均实现四步创建向导、影响预览、任务详情及高风险二次确认。

## 验证

- `npm.cmd test`：根门户与三端构建成功，44 项测试通过。
- `npm.cmd run lint`：通过。

## 已知限制

- OTA 进度由显式操作驱动的确定性 Mock 事件推进，不连接真实设备。
- “推进批次（模拟超阈值）”用于稳定复现自动暂停场景。

# CHG-2026-09-11-003：固件文件管理

## 需求

- IOT-FIRMWARE-001

## 变更

- 扩展固件文件、校验状态、适配产品、创建信息、操作历史和 OTA 引用契约。
- Mock API 支持固件登记、版本比较、发布/归档、删除及 OTA 可用性校验。
- 校验重复版本、20 MB 上限、BIN/ZIP 类型、浏览器读取失败、SHA-256、租户产品兼容性与权限。
- React、Vue、Angular 均在浏览器读取本地文件并计算 SHA-256，仅提交可复现元数据，不上传二进制。
- 被 OTA 引用的固件不能归档或删除，并返回具体引用任务。

## 验证

- `npm.cmd test`：根门户与三端构建成功，40 项测试通过。
- `npm.cmd run lint`：通过。

## 已知限制

- 文件内容只用于本地哈希计算，不做持久化或网络上传。
- 操作历史与 OTA 引用存储于当前 Mock API 实例。

## 变更

- 新增 `TopologyQuery`、`TopologyNode` 与 `TopologyResult` 共享 DTO。
- Mock API 支持租户、洲、国家、节点、产品和设备状态筛选。
- 节点统一返回设备数、在线数、消息量、告警数和最后活动时间聚合。
- 有坐标设备与未定位设备均返回完整 `Device`，可继续访问同一设备详情。
- React、Vue、Angular 的拓扑摘要适配统一契约。
- React、Vue 与 Angular 拓扑页新增洲筛选、节点下钻路径、离线列表替代视图和设备地理详情；React 同时提供设备详情路由入口。
- React、Vue、Angular 新增无在线瓦片依赖的坐标投影地图，地图点响应洲筛选并可点选查看设备详情；状态同时使用颜色和文本/可访问名称表达。
- `EdgeNode` 新增固定城市级坐标，三端以带设备数量的圆环展示节点聚合点，并与单设备状态点形成非颜色区分。
- ESLint 排除构建产物并修复看板本地状态的惰性初始化，恢复可执行的源码静态检查。

## 验证证据

2026-09-07 在 `code/` 执行 `npm.cmd test`：根门户与 React、Vue、Angular 构建成功，15 项测试全部通过。新增用例覆盖三端地理交互结构、洲筛选、聚合守恒、设备详情一致、未定位设备、组合筛选和租户隔离。执行 `npm.cmd run lint` 通过。

## 已知限制

本增量完成共享查询契约、三端下钻交互、节点聚合点和设备状态点。地图使用简化离线坐标底图而非精细国家边界矢量图；筛选、点选、未定位设备和离线运行验收路径均已覆盖。

# CHG-2026-09-11-007：Dashboard 验收闭环

## 需求

- IOT-DASH-001

## 变更

- 扩展共享 Dashboard 响应：五项指标、同期对比、更新时间、地域分布、国家/节点排行、吞吐趋势、告警分布和带文本等级的倒序事件。
- 时间范围直接影响消息聚合；地域、时间、租户和 seed 使用同一查询边界。
- React、Vue、Angular 均加入 24h/7d/30d、地域、空数据和异常场景控制，并分别展示加载、局部失败、无权限、离线和正常状态。
- 三端加入事件暂停/恢复说明，暂停不删除已接收事件；主题偏好持久化到 LocalStorage。
- 指标与分析区域在窄屏改为纵向布局，不产生卡片横向遮挡。

## 验证

- `npm test`：54 项测试通过，包含四个生产构建、聚合守恒、时间联动、空范围、事件顺序及三端状态标记。
- `npm run lint`：通过。

## 已知限制

- 项目为固定 seed 的纯前端演示，事件暂停/恢复模拟展示状态，不建立真实网络订阅。

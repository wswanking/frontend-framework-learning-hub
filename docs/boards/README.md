# 看板使用说明

这里是仓库内的流程事实源。所有看板均使用稳定编号、状态、负责人、AI 辅助说明、证据链接和最后更新时间。AI 可以创建与更新条目，但不得把“待审核”改为“已批准”。

| 看板 | 文件 | 管理对象 |
| --- | --- | --- |
| 需求看板 | `REQUIREMENTS.md` | 需求范围、优先级、阶段与验收 |
| 任务看板 | `TASKS.md` | 可执行开发、测试、文档和发布任务 |
| Issue 看板 | `ISSUES.md` | 缺陷、风险、技术债与阻塞 |
| 待审核列表 | `REVIEW-QUEUE.md` | 必须人工介入的决策、产物和发布门禁 |

状态与定义以 [`../process/DELIVERY-LIFECYCLE.md`](../process/DELIVERY-LIFECYCLE.md) 为准。

## 阶段完成标准

每一阶段必须：需求看板状态更新、任务拆分完成、实现通过对应测试、Issue 已处理或明确接受、变更记录已创建、所需人工审核已通过。

## 推荐首个开发迭代

先执行顺序 1：`IOT-DOMAIN-001`。它是三端、Dashboard、地图、产品、设备、规则和 OTA 的共同底座。该阶段的第一步不是编码，而是提交领域类型、数据字典、权限矩阵、Mock 查询/命令/事件契约，等待 REVIEW-003 批准。

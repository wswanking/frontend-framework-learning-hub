# IoT Atlas 发布环境矩阵

| 环境 | 用途 | 数据与权限 | 触发方式 | 准入条件 |
| --- | --- | --- | --- | --- |
| local | 开发与快速验证 | 本地固定 seed Mock；开发者权限 | `npm run dev` 或三端 `dev:*` | ESLint 与目标测试通过 |
| preview | 产品、测试与跨框架评审 | 固定 seed Mock；私有受控链接 | 主分支候选版本手动/CI 私有部署 | 全构建、测试、变更记录、预览发布记录和回滚步骤齐全 |
| production | 正式演示与交付 | 已验收版本；只读演示数据 | 用户授权的自动化发布 | 全部门禁、零未处理高严重度 Issue、自动化验收通过、上一已验证版本可回滚 |

运行时不使用真实设备、身份、固件或生产数据。托管绑定仅允许 `.openai/hosting.json` 中声明的逻辑 D1/R2；当前均为 `null`。

所有环境使用显式 seed `20260829`。preview 与 production 不接收浏览器外部密钥，构建产物不得写入凭据。

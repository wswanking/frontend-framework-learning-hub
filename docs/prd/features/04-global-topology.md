## 目标与边界

以离线地理数据展示洲、国家、边缘节点和设备的位置、连接状态与数据量。地图为分析界面，不提供真实地理围栏和导航服务。

## 页面与交互

- 地图层：六大洲、国家边界、节点聚合点和设备点；缩放级别决定显示密度。
- 筛选：租户、产品、设备状态、洲/国家、节点、时间范围。
- 详情抽屉：显示名称、坐标、在线率、设备数、消息量、告警数和最后活动时间。
- 下钻链路：洲 → 国家 → 节点 → 设备，面包屑支持返回上级。

## 业务规则

- 坐标为演示数据，精度限制到城市级；不得暗示真实设备位置。
- 同一设备只属于一个节点和国家；节点数据量是当前时间范围内其设备消息量之和。
- 地图点聚合阈值和排序规则由契约统一定义。

## 权限与异常

观察员只读；无坐标设备进入“未定位设备”列表。地理数据缺失时显示列表替代视图；不可依赖需要密钥的在线瓦片。

## 验收条件

- Given 选择亚洲，When 查询，Then 地图、列表和统计仅包含亚洲数据。
- Given 节点无坐标，When 查看地图，Then 设备不会消失，并能从未定位列表访问。
- Given 点击设备点，When 打开详情，Then 显示与设备详情页一致的 ID 和状态。

## 2026-09-20 抽屉焦点与时间错误反馈增量

三端地理详情抽屉打开后接收键盘焦点，按 Escape 或点击关闭后焦点返回列表、未定位设备或地图的触发入口。自定义 UTC 时间提交失败时，错误显示在时间输入旁并聚焦首个无效字段；输入与错误通过 `aria-invalid` 和 `aria-describedby` 关联。失败保留草稿和上次已应用的地图查询，输入错误不再显示数据请求“重试”。有效应用或重置清除输入错误。V2 人工审核和最终验收仍待完成。

## 2026-09-20 地图空白取消选中增量

三端桌面地图点击空白画布时关闭已选对象详情，不改变缩放、筛选或地理层级；点击设备点及聚合点仍按原路径下钻。手机详情抽屉覆盖地图时，可用 Escape 或关闭按钮退出。最终交互审核仍待完成。

## 2026-09-20 跨身份与租户旧数据清理增量

三端地理页切换演示身份或应用其他租户时，立即清除上一身份或租户的地图结果与详情，等待新范围查询。无权限响应清除旧结果，不以“非最新”保留受限数据；同一身份和租户的离线失败仍保留上次成功结果并标记“非最新”。此为本端浏览器 Mock 的展示隔离，真实身份认证和最终权限验收仍待完成。

三端地理页仅对可重试的服务失败显示“重试”；无权限错误只解释原因，不提供无效重试。

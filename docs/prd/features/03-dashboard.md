| 审核门禁 | REVIEW-002 |

## 目标与边界

让平台管理员在一个页面理解全球设备、消息、告警和 OTA 的运行态势。大盘只展示聚合数据和可下钻入口，不承担设备配置与告警处置。

## 页面与交互

1. 顶部：租户、时间范围（24h / 7d / 30d / 自定义）、地域筛选和主题切换。
2. 指标：接入设备、在线率、消息量、活跃告警、OTA 成功率；均展示本期值、对比值和更新时间。
3. 分析：全球地图、六大洲分布、国家/节点排行、消息吞吐趋势、告警分布、实时事件流。
4. 下钻：点击洲、国家、节点或排行项，保持当前筛选条件进入对应详情。

## 业务规则

- 所有卡片与图表由同一 DashboardQuery 聚合，时间边界使用 `[start, end)`。
- 实时事件倒序显示；暂停或恢复不丢失已接收事件。
- “在线率”分母为当前筛选范围的已激活设备；空范围显示 `—`，不显示 0%。
- 事件和告警至少用图标/文本加颜色区分等级。

## 权限与异常

平台管理员可查看全局；租户管理员仅查看所属租户；观察员只读。加载、无数据、部分失败、无权限和离线必须独立呈现。

## 验收条件

- Given 选择租户和 7 天，When 查询，Then 所有指标、地图、排行和趋势使用相同过滤范围。
- Given 点击一个国家，When 下钻，Then 进入该国家节点列表并保留租户和时间条件。
- Given 窄屏设备，When 打开大盘，Then 指标、图表摘要和事件列表可读取且不横向遮挡。

## 2026-09-20 库存联动增量

三端大盘查询从各自设备服务读取当前库存，导入/删除后刷新页面更新设备数与地域聚合；未激活设备不进入在线率分母。消息、告警与 OTA 指标的动态事件联动及最终验收仍待完成。

## 2026-09-20 告警与 OTA 记录联动增量

三端大盘活跃告警、告警分布和告警创建事件改为读取本端设备告警、规则演示日志和 OTA 阈值告警；确认后活跃数减少，历史创建事件保留。OTA 成功率改由时间范围内已结束的设备执行记录计算；没有已完成执行时显示 `—`。计算规则见 [Mock API 契约](../../architecture/contracts/MOCK-API.md)。实时遥测后台订阅、完整事件流与最终验收仍待完成。

## 2026-09-20 新增遥测消息联动增量

三端大盘消息卡、吞吐趋势、地域排行与事件流在相同筛选和时间窗内计入本端设备消息服务新增的去重原始报文；初始种子快照不重复叠加。地理页采用相同增量以保持跨页面消息量一致。seed 演示基线仍保留，独立后台采集与真实消息存储尚未接入。

## 2026-09-20 浏览器 Mock 实时事件增量

三端大盘在本端原始消息或告警确认写入后自动重查当前已应用筛选，也监听同源标签页的设备库存、消息、告警确认和 OTA 存储变化。事件列表可暂停、恢复；暂停期间其他指标继续更新，新增事件保留并显示条数，恢复后回到事件顶部。滚动查看事件历史会自动暂停。切换租户或演示身份时清空旧范围数据及待显示事件。这里的实时性仅由本端浏览器事件与同源存储通知驱动，不代表后端推送或跨设备同步。

## 2026-09-20 事件等级呈现增量

三端大盘事件流保留设备告警的原始等级：故障为紧急、规则预警为一般、OTA 灰度阈值告警为重要；遥测单独标为信息事件。列表用图标、文字和颜色共同表达等级，历史事件在确认告警后仍保留原等级。等级映射见 Mock API 契约；人工视觉审核和最终验收仍待完成。

## 2026-09-20 洲与节点下钻增量

三端大盘的洲概览可点击并以当前租户、UTC 起止时间重新查询对应地域；国家排行和地图维持国家摘要抽屉，摘要中的节点列表可打开节点详情，查看设备数、消息量和城市级演示坐标，再返回国家节点。路径记录在本端大盘 URL，切换筛选会清除旧下钻。地理页的跨页精确层级链接与完整设备下钻仍待补齐。

三端现已从洲概览、国家摘要和节点摘要提供地理页链接，沿用当前租户和精确 UTC 起止时间并进入对应面包屑层级；地理页支持自定义时间范围。设备详情下钻及最终交互验收仍待补齐。

## 2026-09-20 节点设备详情下钻增量

三端节点详情现列出当前租户、地区和产品筛选结果中的设备 ID，点击可进入对应设备详情。节点设备列表按 ID 排序；消息量仍按当前时间范围统计。最终交互验收仍待人工结论。

## 2026-09-20 地图视角控件增量

三端 Dashboard 地图增加可聚焦的放大、缩小与回到全球视角按钮，与图稿 02 的地图控件对应。视角缩放范围为 1–5 倍；操作不改变当前 Dashboard 查询或下钻 URL。国家仍可从地图点击或排行列表用键盘打开。桌面和移动浏览器用例已覆盖控件操作，视觉图稿与最终验收仍待审核。

## 2026-09-20 规则告警本页刷新增量

三端在浏览器 Mock 规则执行日志写入后发出本页数据变更通知，使已打开的 Dashboard 重新聚合告警指标和事件流。实时遥测仍先写入消息，再消费规则；若规则产生告警，会收到第二次刷新通知。此机制只作用于本端浏览器 Mock，不代表独立后台事件推送。

## 2026-09-20 平板导航与关键读操作增量

三端在 1100px 及以下视口将侧栏折叠为顶部可横向滚动导航；平板继续使用三列指标布局，手机使用两列。820px 平板视口下验证 Dashboard 指标与地图，以及九个业务路由的标题可读且页面不横向溢出。此为响应式增量，V2 人工交互和视觉验收仍待完成。

## 2026-09-20 手机筛选收纳增量

三端 Dashboard 在 720px 及以下将租户、时间、地域及演示状态筛选收纳为可展开面板，默认收起；桌面和平板继续直接展示筛选。有效应用或重置后面板收起，校验失败时保持展开并保留输入。筛选草稿仍只在应用后更新大盘，地图与指标保持可读。移动交互与视觉最终验收仍待完成。

## 2026-09-20 详情抽屉键盘焦点增量

三端 Dashboard 打开国家或节点详情抽屉时将键盘焦点移入抽屉；按 Escape 或点击关闭后，将焦点返回原下钻入口。由国家抽屉继续打开节点详情时，保留国家列表中的原入口作为返回焦点。抽屉获得焦点时显示可见轮廓。此项遵循统一交互原则，人工视觉审核与最终验收仍待完成。

## 2026-09-20 自定义时间校验反馈增量

三端 Dashboard 自定义时间提交失败时，在时间输入旁显示错误并聚焦首个无效字段；输入通过 `aria-invalid` 与错误说明关联。失败保留草稿、已应用查询和移动筛选面板状态，避免把输入错误误报为数据请求失败或提供无效的“重试”操作。有效应用或重置清除输入错误。

## 2026-09-20 无权限与可重试错误反馈增量

三端 Dashboard 收到无权限响应时清除旧指标，不再标为“非最新”或显示无效的“重试”；离线等可重试服务失败仍保留上次成功数据，并提供重试操作。无权限时不显示通常用于空查询的“调整筛选或重试”占位。

切换演示身份或收到无权限响应时，三端同时清除暂停事件及待显示事件、国家与节点详情，并从大盘 URL 移除详情选择。恢复有权身份后重新读取当前查询，事件列表默认继续更新，旧详情不会自动重新打开。演示无权限场景也清除这些状态；同身份离线时仍按上段保留可标记的旧数据。

## 2026-09-20 刷新时间与统计时间区分

三端标题区提供手动“刷新”和最近一次成功获取大盘数据的本地时间；指标卡把查询时间窗终点明确标为“统计截至”。刷新沿用已应用的筛选，失败时不伪造新的成功时间；无权限且无可展示数据时显示 `—`。本地时间仅说明浏览器何时成功读取 Mock，不代表设备遥测实际采集时间。

## 2026-09-20 事件查看全部入口

三端实时事件卡增加“查看全部”与“收起事件”切换。前者展开当前 DashboardQuery 已返回的完整倒序事件列表，取消卡片内高度限制；后者恢复卡片内滚动区域。展开不改变租户、时间筛选、事件暂停状态或 URL；该入口不表示跨时间窗读取历史事件。

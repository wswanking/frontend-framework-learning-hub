# PRD：发布、回滚与验收

| 项目 | 内容 |
| --- | --- |
| 需求编号 | IOT-RELEASE-001 |
| 优先级 | P1 |
| 状态 | 三端发布清单 Mock 增量已实现，真实发布/回滚与最终验收未完成（2026-09-20） |
| 验收门禁 | 用户授权的自动化发布门禁 |

## 目标与边界

定义前端项目从本地验证到预览、正式发布和回滚的可审计流程。当前不绑定具体云厂商或发布平台，但所有发布证据必须归档在仓库。

## 环境与交互

| 环境 | 用途 | 数据/权限 | 准入 |
| --- | --- | --- | --- |
| local | 开发和快速验证 | 本地 Mock、开发者 | 静态检查和目标测试 |
| preview | 产品/测试评审 | 固定 seed Mock、受控链接 | 构建通过、变更记录、测试证据 |
| production | 正式演示/交付 | 已批准版本、只读演示数据 | 全部门禁通过、发布负责人批准 |

发布记录必须包含版本、提交/变更、需求/任务/Issue、环境、测试结果、已知风险、负责人、回滚步骤和验收链接。

## 业务规则

- production 发布前：构建与测试通过；高严重度 Issue 已关闭或被正式豁免；所有阻塞审核已有结论；回滚版本可用。
- 每个关联需求必须至少有一个审核条目；缺少审核条目或关联审核尚未通过时，正式发布清单均判定阻塞。预览环境将其列为警告。
- 正式发布清单还必须检查 `REVIEW-005` 的发布审核结论；该审核缺失或未通过时阻塞 production，预览环境给出警告。
- 任何部署失败、性能/功能异常或验收拒绝都创建 Issue 和变更记录。
- 回滚只允许回到上一已验证版本；回滚后必须补充原因、影响和复验结论。

## 验收条件

- Given 预览发布，When 生成发布记录，Then 可追溯到需求、任务、测试和审核材料。
- Given 缺少回滚步骤或审核结论，When 尝试标记正式发布，Then 发布清单判定不准入。
- Given 发布后发现阻塞问题，When 回滚，Then 记录版本、原因、时间、负责人和回滚后的验证结果。

## 本轮验收方式

用户已明确授权“无需审核，满足验收标准就行”。正式发布须通过全仓构建、测试、静态检查、零未处理高严重度 Issue、上一已验证版本与完整回滚步骤检查；结果写入验收记录。

## 2026-09-20 实施增量

三端各自实现本地发布记录草案和阻塞清单 Mock。正式环境缺少测试证据、上一已验证版本、回滚步骤、关联审核结论或存在未关闭高严重度 Issue 时不可标记模拟发布。此清单尚未读取 CI 或执行部署；它不能用作真实发布准入证据。

## 2026-09-20 无审核条目门禁修复

三端正式发布清单现在逐个检查关联需求是否存在审核条目。没有条目的需求明确显示“关联需求缺少审核”，不再显示“关联审核已有结论”；已存在但未通过的审核仍按原规则阻塞。该本地 Mock 检查不代表正式审核批准。

## 2026-09-20 发布专项审核门禁修复

三端发布清单现在同时检查 `REVIEW-005`。即使业务需求关联审核已模拟通过，`REVIEW-005` 未通过时正式发布仍被阻塞；预览环境只显示警告。测试中的通过结论仅验证本地 Mock 状态流转，不是实际审核结论。

## 2026-09-20 需求重新审核门禁

三端本地发布清单检查每个关联需求本身是否仍为已批准。已批准需求修改范围后，即使旧审核曾通过，需求和关联审核都会退回待审核，正式环境据此阻塞，预览环境给出警告。该检查只验证本端 Mock 记录状态；真实 CI 证据、上一已验证版本和实际部署准入仍须另行核验。

## 2026-09-20 清单可追溯与材料补正

三端创建发布记录时按通过、警告、阻塞展示检查项，标出下一责任人。缺少本次表单材料可定位到字段；关联审核、Issue 或需求阻塞可打开对应 Mock 记录。已保存的发布记录详情保留同样的分组结果；发布负责人可补正尚未发布的记录，系统追加修订历史并重算准入。已发布或已回滚记录不可补正。以上仍是浏览器本地 Mock，不读取真实 CI、不校验上一版本产物或执行部署。

## 2026-09-20 CI 诊断证据

隔离的三端 CI 作业在本端诊断、浏览器测试和两种候选截图采集成功后，各自生成 `reports/ci-evidence.json`。记录包含提交和 CI 运行链接、检查结论、JUnit 测试计数、报告及构建文件 SHA-256、V2 候选数量；报告失败、截图哈希不符或检查缺失时不生成成功证据。这份记录供发布负责人核对真实 CI 运行，不能单独替代阻塞审核结论、上一已验证版本、回滚步骤、设计批准或实际部署验收。

## 2026-09-20 三端候选构建产物汇总

外层构建调度三端各自的生产构建，并将独立输出复制到一个含提交号、文件大小和 SHA-256 的候选包；篡改或缺失文件时复核失败。CI 工作流增加候选包上传步骤。该产物只供发布负责人核对和留档，不代表已生成可部署的统一站点，也不替代真实远端 CI 运行、预览/正式部署、回滚或最终验收。

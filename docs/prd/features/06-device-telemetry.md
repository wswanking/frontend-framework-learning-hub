## 目标与边界

提供设备全生命周期浏览、诊断和浏览器内控制模拟。包括列表、详情、地理位置、影子数据、原始消息、告警和时序数据；不连接真实设备。

## 页面与交互

- 列表支持产品、状态、地域、标签、最后活跃时间筛选，支持搜索、排序、分页和批量选择。
- 详情包括概览、实时属性、时序、消息、告警、位置、规则执行和 OTA 历史。
- 时序支持指标选择、时间范围、采样粒度、缩放、悬浮提示、导出和实时追加。
- 控制面板根据物模型生成可写属性/服务表单，提交后展示命令状态。

## 业务规则

- 设备状态为未激活、在线、离线、故障、维护；最后活跃时间决定在线状态的 Mock 判定。
- 时序查询使用设备、指标、时间范围和采样粒度；缺点必须以空洞或缺失说明呈现，不伪造连续值。
- 控制命令在设备离线时进入失败或等待状态，不能直接报告成功。

## 权限与异常

观察员只能查看；运维工程师可操作控制和告警确认；租户管理员可编辑元数据。时序无数据、设备删除、数据查询失败均有独立状态。

## 验收条件

- Given 按在线和产品筛选，When 查询设备，Then 结果、总数和分页一致。
- Given 选择两个指标和一天范围，When 查看时序，Then 可比较两条曲线并显示对应单位。
- Given 离线设备执行控制，When 提交，Then 命令记录为失败或等待，且保留原因。

## 2026-09-19 补充

三端设备页均加入登记入口：选择租户、该租户已发布的产品、名称与地域，创建为未激活设备。服务层校验角色、租户、产品与设备数硬配额，并将结果写入本端浏览器 Mock。新建租户在本端发布产品后即可登记设备；桌面和移动跨页流程已自动化验证。此项增量不等于设备导入、删除或最终验收完成。

## 2026-09-20 消息与告警增量

三端设备详情消息页签显示带时间和报文的确定性属性上报，并将当前页实时订阅的有效遥测保存为本端原始消息；全缺失点跳过，同设备同时间点去重。告警页签显示故障设备、规则执行及 OTA 灰度失败超阈值的模拟告警，运维及管理员可确认，观察员只读；确认人和时间保存在本端浏览器存储。消息与告警来源仍为浏览器 Mock，未完成最终验收。

规则执行日志分页时，设备告警需读取所有匹配页并按完整设备 ID 筛选，避免第 100 条以后的告警丢失或相似 ID 的告警混入。

## 2026-09-20 批量导入与删除增量

三端设备列表支持选择目标租户和该租户已发布产品，上传 `name,region,countryCode,tags` CSV（标签用 `|` 分隔），预览本批数量及租户设备数变化后确认导入。一次 1–100 台；服务层逐行验证、检查角色与配额，整批成功或整批不写入。列表勾选后可预览所选 ID 并确认批量删除；取消不修改数据，历史规则与 OTA 记录保留。导入与删除只允许平台或租户管理员，跨租户请求由服务层拒绝。导入及删除仅修改本端浏览器 Mock，设备全生命周期、交互审核与最终验收仍未完成。

## 2026-09-20 时序提示增量

三端时序图的数据点均显示时间、值和单位的悬浮提示；缺失点继续以曲线断开和数值表中的“缺失”呈现。图稿审核与最终验收仍待完成。

## 2026-09-20 自定义时间范围增量

三端时序页可输入 UTC 起止分钟，服务查询使用对应绝对时间；页面先校验真实日期、起止顺序与 30 天上限，超出单次采样点上限时沿用服务错误提示。24 小时、7 天和 30 天预设仍可切回。时间范围当前只在设备页会话内保持，未提供跨浏览器保存。

## 2026-09-20 设备影子增量

三端设备详情增加只读“设备影子”页签，逐属性显示本端已上报值和待执行命令的期望值。命令成功后，Mock 将可写属性的期望值清空并更新已上报值；失败命令不改变已上报值。影子沿用设备租户隔离，属性及命令在本端浏览器持久化。这里的命令回执是浏览器模拟，不代表真实设备确认；完整交互审核与最终验收未完成。

## 2026-09-20 实时遥测汇入影子增量

三端设备页开启实时追加时，有效遥测点更新本端设备属性和影子已上报值，并保存到本端浏览器；缺失、无效或早于最后活跃时间的点不覆盖现值。关闭订阅或离开时序页后不再追加。该链路仍只在设备页订阅运行，不是后台设备接入。

## 2026-09-20 时序缩放查询增量

三端点击“放大后半段”时，以当前所选 UTC 时间范围的中点为起点重新查询本端时序 Mock；点击“恢复全范围”时重新查询原范围。图表、缺失提示、数值表与 CSV 导出均使用当前查询结果，查询期间清除旧结果。此交互仍待 V2 人工审核与最终验收。

## 2026-09-20 跨页批量导出增量

设备列表跨页勾选后，批量 CSV 导出包含全部已选设备，而非仅当前页；导出前按已选 ID 读取本端设备服务，任一设备读取失败则提示原因并取消本次下载，避免生成不完整文件。筛选查询与重置仍清空勾选，翻页保留勾选。

## 2026-09-20 时序无数据引导增量

三端时序查询的全部点缺失时，显示当前查询结果覆盖的 UTC 起止时间，并提供“调整时间范围”按钮，将键盘焦点移至范围选择控件。用户可在原页修改时间范围或采样粒度后重试；此状态仍待 V2 人工审核。

## 2026-09-20 控制预览布局增量

三端从实时属性提交控制参数后，确认预览从视口右侧展开，显示目标设备、命令、参数、权限与在线状态，并在底部提供发送和取消。发送仍经过服务层模型及权限校验，离线设备或观察员仍无法触发预览。此布局按 V2 图稿 05 调整，图稿符合性尚待人工审核。

控制预览打开后键盘焦点进入面板；Tab 和 Shift+Tab 在面板操作按钮间循环，Escape 取消并回焦“预览命令”。发送后切换到命令记录页签并将焦点移至该页签。身份切换或关闭设备详情时清理未提交的控制预览。

控制预览作为模态面板打开期间锁定背景页面滚动；发送、取消或离开设备页后恢复原滚动设置。

## 2026-09-20 控制拒绝反馈增量

发送控制命令被本端服务拒绝时，预览面板内显示具体原因和参数约束，保留目标与参数供用户核对。取消后修正参数并重新打开预览时清除上次错误；成功提交后进入命令记录。服务层参数和权限校验仍是最终判定。

## 2026-09-20 设备高影响弹窗键盘路径

三端新建设备、CSV 导入和批量删除确认弹窗打开后接收焦点，Tab/Shift+Tab 在弹窗可用控件内循环，Escape 取消并将焦点返回触发按钮。删除弹窗仍展示所选设备 ID 和影响说明；取消不修改库存。

弹窗打开期间锁定页面背景滚动，关闭或离开页面后恢复原滚动设置；移动端导入弹窗的滚轮验证覆盖此行为。

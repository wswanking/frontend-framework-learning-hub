## 目标与边界

以可视化流程模拟设备数据的触发、判断、转换、告警和存储动作。只执行浏览器内的确定性样例数据，不触发真实通知或外部系统。

## 页面与交互

- 规则列表：名称、产品、启用状态、最近执行、成功率和版本。
- 编排画布：触发器、条件、转换、延迟、告警、存储、通知节点；支持连接、配置、校验和版本备注。
- 试运行：选择样例报文，逐节点展示输入、输出、耗时、匹配结果和失败原因。
- 执行日志：按规则、设备、时间、状态筛选，可跳转到对应设备。

## 业务规则

- 一个规则必须有一个触发器、至少一个动作，且图中不得存在循环依赖。
- 条件组支持 AND / OR；表达式执行必须设定超时和安全白名单。
- 禁用规则不消费实时事件；试运行不改变真实 Mock 设备状态，除非明确选择“应用模拟结果”。

## 权限与异常

租户管理员可编辑/启停，运维工程师可试运行，观察员只读。无效连线、缺少字段、表达式错误、超时和动作失败必须标出具体节点。

## 验收条件

- Given 完整规则和样例报文，When 试运行，Then 每个节点都有可追踪输入与输出。
- Given 规则存在环，When 保存，Then 阻止保存并标记环路节点。
- Given 禁用规则，When 收到匹配事件，Then 不创建执行记录或告警。

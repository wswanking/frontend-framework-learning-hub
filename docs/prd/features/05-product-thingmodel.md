## 目标与边界

让租户管理员定义产品能力、物模型和设备 DP 数据转换规则。只模拟配置和校验，不向真实设备下发模型。

## 页面与交互

- 产品列表：名称、类别、接入协议、设备数量、状态、更新时间；支持搜索、筛选和分页。
- 产品详情：基础信息、接入配置、物模型、DP 规则、设备五个页签；保存前校验并提示未保存变更。
- 物模型：属性、事件、服务；支持表单编辑、JSON 预览和字段级校验。
- DP 规则：原始值、数据类型、倍率、偏移、精度、枚举映射、阈值、表达式与样例输入输出测试。
- 设备页签：按当前产品及租户查询关联设备，显示总数、每页 10 台的列表和状态；设备名称可进入本端设备详情。没有关联设备时显示明确空状态。

未保存变更、关键影响和不兼容数据类型切换均使用确认弹窗。弹窗打开后键盘焦点进入弹窗，Tab 在弹窗操作内循环，Escape 取消；关闭后焦点返回触发控件。数据类型控件在 Angular 条件渲染中重建时，回焦到重新渲染的同名控件。

## 业务规则

- 物模型标识在同一产品内唯一；属性含读写权限、单位、范围或枚举。
- DP 规则必须绑定产品和物模型项；转换结果必须满足目标数据类型和范围。
- 已有关联设备的产品，删除物模型项或修改关键数据类型必须给出影响提示并要求确认。

## 权限与异常

租户管理员可编辑，运维工程师只读。表达式无效、循环映射、枚举重复、数据越界和冲突保存需给出具体错误。

切换演示身份时，产品页立即清除旧身份的列表、勾选和详情，按新身份租户重新查询。进入演示无权限场景或收到 `FORBIDDEN` 响应时，清除列表、详情及未提交的确认弹窗；恢复有权场景后重新查询。此规则仅约束本端 Mock 展示状态，不替代真实认证。

## 验收条件

- Given 创建温度属性，When 保存，Then 必填标识、数值范围、单位和读写权限均被校验。
- Given 输入原始 DP 值，When 运行转换测试，Then 展示每一步转换及最终值或错误。
- Given 非管理员，When 访问编辑页，Then 不显示保存操作且不能提交修改。

## 2026-09-20 接入配置增量

三端接入配置页签各自保存协议对应的上下行路径、报文格式和心跳间隔，并支持未保存提醒、字段校验、版本冲突及租户权限检查。更改协议时先提示旧路径将重置，确认后才写入新协议默认路径；已有设备的 Product Key 修改也先提示影响。它仅记录本端浏览器 Mock 元数据，不存接入凭据、不连接真实设备或 Broker；具体认证与部署方案仍须单独评审。

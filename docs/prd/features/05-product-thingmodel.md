## 目标与边界

让租户管理员定义产品能力、物模型和设备 DP 数据转换规则。只模拟配置和校验，不向真实设备下发模型。

## 页面与交互

- 产品列表：名称、类别、接入协议、设备数量、状态、更新时间；支持搜索、筛选和分页。
- 产品编辑：基础信息、接入配置、物模型、DP 规则四个页签；保存前校验并提示未保存变更。
- 物模型：属性、事件、服务；支持表单编辑、JSON 预览和字段级校验。
- DP 规则：原始值、数据类型、倍率、偏移、精度、枚举映射、阈值、表达式与样例输入输出测试。

## 业务规则

- 物模型标识在同一产品内唯一；属性含读写权限、单位、范围或枚举。
- DP 规则必须绑定产品和物模型项；转换结果必须满足目标数据类型和范围。
- 已有关联设备的产品，删除物模型项或修改关键数据类型必须给出影响提示并要求确认。

## 权限与异常

租户管理员可编辑，运维工程师只读。表达式无效、循环映射、枚举重复、数据越界和冲突保存需给出具体错误。

## 验收条件

- Given 创建温度属性，When 保存，Then 必填标识、数值范围、单位和读写权限均被校验。
- Given 输入原始 DP 值，When 运行转换测试，Then 展示每一步转换及最终值或错误。
- Given 非管理员，When 访问编辑页，Then 不显示保存操作且不能提交修改。

# PRD：租户、成员与配额

| 项目 | 内容 |
| --- | --- |
| 需求编号 | IOT-TENANT-001 |
| 优先级 | P1 |
| 状态 | 三端 Mock 与页面增量已实现，交互审核及最终验收未完成（2026-09-19） |
| 审核门禁 | REVIEW-003 |

## 目标与边界

模拟多租户资源隔离、成员角色、功能权限和资源配额。仅实现 Mock 身份与本地数据，不建立真实身份认证。

## 页面与交互

- 租户列表：名称、状态、成员数、设备数、消息量和配额使用率。
- 租户详情：概览、成员、角色、配额、产品和设备入口。
- 成员管理：邀请模拟、角色变更、停用与移除；展示权限预览。
- 配额管理：设备数、产品数、消息量、存储量、OTA 并发数；展示已用、预警和超限状态。

## 业务规则

- 每个资源属于唯一租户；跨租户查询或操作一律拒绝。
- 内置角色为平台管理员、租户管理员、运维工程师、数据观察员；权限矩阵由共享契约定义。
- 达到配额预警时可查看但创建受提示；达到硬上限时拒绝创建并返回原因。

## 验收条件

- Given 观察员，When 访问成员编辑，Then 不显示编辑操作。
- Given 租户达到设备上限，When 创建设备，Then 操作失败并显示已用/上限。
- Given 切换租户，When 访问列表和大盘，Then 不显示上一租户任何资源。

## 2026-09-19 实施记录

React、Vue、Angular 各自实现独立的租户、成员、角色预览和五类配额 Mock、`/tenants` 页面及本地持久化。租户可创建和编辑；新租户自动生成首位租户管理员。成员可模拟邀请、变更角色、停用和移除，最后一位有效租户管理员不可移除。配额编辑提供影响预览，设备、产品创建和 OTA 启动、恢复达到硬上限时由服务层拒绝并返回已用/上限。新租户可在产品页发布产品后登记设备；当前租户选择会传到产品、设备和大盘入口。

当前权限按 `PERMISSIONS.md` 执行：仅平台管理员可改租户、成员和配额；租户管理员只读本租户。总 PRD 中“租户管理员管理本租户成员”与该契约冲突，待用户确定后统一修订。消息量和存储量目前展示确定性 Mock 已用值及预警，但没有对应写入流程可执行硬上限拒绝。成员邀请不发送邮件；所有数据仅存本端浏览器。自动化通过不代表 REVIEW-003 或最终验收已批准。

## 2026-09-20 原始消息配额联动增量

三端租户配额各自把本端新增且去重的原始遥测报文计入 seed 消息基线，排除初始演示快照；消息达到硬上限后，设备消息服务拒绝保存下一条并返回已用/上限，同一条已保存报文重复提交仍返回原记录。设备时序页显示原始消息未保存的配额原因。存储量仍为确定性 Mock，没有存储写入链路。

## 2026-09-20 设备登记配额预警

三端新建设备弹窗在选定租户后查询本端设备配额，展示已用量和上限；若登记下一台会进入或超过预警百分比，确认前显示预警阈值。切换目标租户重新查询，较早的异步结果不覆盖当前租户提示。该提示不代替设备服务在提交时重新检查硬上限；CSV 导入仍使用其独立的整批预览与拒绝路径。

## 2026-09-20 产品创建配额预警

三端新建产品抽屉查询所选租户的产品已用量与上限。若保存下一项会达到预警百分比，保存前显示阈值提示；切换租户会刷新，编辑现有产品时不显示创建配额提示。产品服务仍在保存时独立检查硬上限。

## 2026-09-20 OTA 并发预警

三端 OTA 任务详情在草稿启动前、暂停任务继续前查询目标租户的并发已用量与上限；下一任务进入预警区间时显示阈值。运维工程师继续任务时沿用服务层相同的租户范围检查；观察员不显示操作预览。启动、继续及回滚仍由 OTA 服务在执行时独立检查并发硬上限。此前阶段存储量配额仍没有写入链路。

## 2026-09-20 固件登记与存储量配额联动

三端租户存储已用量现按原 seed 基线加上本端新登记固件的文件大小计算，所有新固件合计后向上取整为 MiB；删除未被引用的固件元数据会释放对应逻辑用量。固件新建第三步展示已用、上限与预计用量，达到软预警或超过硬上限时显示提示；固件服务在提交前重新核对硬上限并拒绝超额登记，降低配额后也不得小于现有用量。浏览器仍仅保存固件元数据与校验值，不保存二进制文件；此处的“存储”是演示用逻辑配额，并非真实对象存储容量。

## 2026-09-20 租户关键状态候选与手机配额弹窗

三端 V2 候选补入租户概览、成员、角色、配额和阻塞预览。手机配额编辑弹窗滚动时，标题与操作栏保持可见；阻塞原因可滚入中间内容区阅读。

## 2026-09-20 配额阻塞处理入口

降低硬上限低于已用量时，三端阻塞预览列出资源、已用和新上限，并允许放弃未保存草稿后进入对应租户的设备、固件或 OTA 页面处理占用。取消放弃时保留配额编辑弹窗。产品和消息历史当前没有清理操作，提示应提高上限；这两类资源不能被误标成可清理。Angular 设备与固件页在站内跳转后会按 URL 租户参数选中相应租户。该入口仍只处理浏览器 Mock 数据，不代替正式权限与交互审核。

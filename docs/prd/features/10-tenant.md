## 目标与边界

模拟多租户资源隔离、成员角色、功能权限和资源配额。仅实现 Mock 身份与本地数据，不建立真实身份认证。

## 页面与交互

- 租户列表：名称、状态、成员数、设备数、消息量和配额使用率。
- 租户详情：概览、成员、角色、配额、产品和设备入口。
- 成员管理：邀请模拟、角色变更、停用与移除；展示权限预览。
- 配额管理：设备数、产品数、消息量、存储量、OTA 并发数；展示已用、预警和超限状态。

## 业务规则

- 每个资源属于唯一租户；跨租户查询或操作一律拒绝。
- 内置角色为平台管理员、租户管理员、运维工程师、数据观察员；权限矩阵由共享契约定义。
- 达到配额预警时可查看但创建受提示；达到硬上限时拒绝创建并返回原因。

## 验收条件

- Given 观察员，When 访问成员编辑，Then 不显示编辑操作。
- Given 租户达到设备上限，When 创建设备，Then 操作失败并显示已用/上限。
- Given 切换租户，When 访问列表和大盘，Then 不显示上一租户任何资源。

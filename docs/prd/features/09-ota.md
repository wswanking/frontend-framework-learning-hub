## 目标与边界

演示从选择固件、选择设备、灰度发布到下载、校验、安装、重启、成功、失败和回滚的完整 OTA 生命周期。所有进度为 Mock 事件。

## 页面与交互

- 创建向导：选固件 → 选产品/设备/标签 → 配灰度批次与失败阈值 → 预览影响 → 创建。
- 任务详情：总体进度、状态分布、批次、设备明细、失败原因、操作日志和版本分布。
- 操作：开始、暂停、继续、取消、失败重试、回滚；高风险操作必须二次确认。

## 状态机与规则

`草稿 → 等待 → 下载 → 校验 → 安装 → 重启 → 成功`；任一步可进入 `失败`，失败后可 `重试` 或 `回滚`；取消进入 `已取消`。

- 任务只能使用已校验且已发布的兼容固件。
- 灰度批次必须按顺序推进；失败率超过阈值自动暂停并创建告警。
- 回滚创建新的反向升级动作，不篡改原任务历史。

## 权限与异常

租户管理员创建和取消，运维工程师暂停/重试，观察员只读。设备离线、版本不兼容、下载失败、校验失败和重启超时均记录具体原因。

## 验收条件

- Given 10% 灰度和失败阈值，When 失败率超过阈值，Then 后续批次不启动且任务暂停。
- Given 升级失败设备，When 重试，Then 保留原失败记录并生成新尝试。
- Given 执行回滚，When 完成，Then 设备版本恢复且原任务历史不被修改。

## 当前增量

三端各自提供五步创建向导、设备与标签选择、灰度/阈值预览、确定性的浏览器 Mock 进度事件、自动阈值暂停与模拟告警、人工暂停/继续/取消、失败重试及独立回滚任务。设备详情 OTA 历史保留原失败尝试与新尝试；单个任务和设备之间可跳转。进度按本地定时器推进，连接断开时提示数据可能过期并可重连；无跨浏览器同步或真实设备升级。本节记录时状态和版本分布只有当前摘要，历史趋势见下方增量。完整视觉审核与最终验收待完成，证据见 [QUALITY](../../architecture/QUALITY.md)。

## 2026-09-20 设备进度历史趋势增量

三端 OTA 任务详情从本端保存的设备阶段事件重建成功、失败、待处理及已取消数量的历史时间线，并显示趋势图与可展开数据表。失败设备重试会在时间线上先恢复待处理，再随着新尝试更新状态；取消任务的设备不再误列为待处理，原失败事件保留。趋势仅反映该任务已有的浏览器 Mock 事件，不是跨浏览器或真实设备的历史采集。

## 2026-09-20 版本分布细化

任务详情按目标设备最新一次执行记录统计当前模拟版本：成功执行计入目标版本，失败、取消或进行中的执行计入其原版本；尚未开始执行的目标单列为“未采集”。重试只计一次，旧失败尝试仍保留在设备明细和历史中。此分布来自任务 Mock 记录，不代表真实设备上报版本。

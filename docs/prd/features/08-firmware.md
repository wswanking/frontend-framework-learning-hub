## 目标与边界

模拟固件文件登记、版本、校验、适配关系和发布状态，为 OTA 提供可信的演示输入。不向服务器上传或保存真实二进制文件。

## 页面与交互

- 文件列表：名称、产品、版本、大小、校验值、状态、创建人和创建时间。
- 新建固件：选择本地文件，输入版本/说明/适配产品，浏览器计算或模拟 SHA-256，预览元数据后提交。
- 详情：版本比较、适配产品、使用中的 OTA 任务、发布/归档状态和操作历史。

## 业务规则

- 版本在同一产品内唯一；正式状态的固件不可覆盖，只能归档或创建新版本。
- 文件类型、大小上限和产品兼容性由 Mock 策略配置；校验失败的文件不得用于 OTA。
- 删除被 OTA 引用的固件必须阻止并显示引用任务。

## 权限与异常

租户管理员可新增/归档，运维工程师可查看，观察员只读。文件过大、重复版本、校验失败、产品不兼容和浏览器读取失败必须说明原因。

## 验收条件

- Given 同产品重复版本，When 提交，Then 阻止保存并显示已有版本。
- Given 校验失败，When 创建 OTA，Then 固件不可选。
- Given 固件被执行中的 OTA 使用，When 归档或删除，Then 显示影响并阻止删除。

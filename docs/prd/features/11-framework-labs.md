## 目标与边界

建立 React、Vue、Angular 三个独立、可运行、可构建、可测试的 IoT 前端工程；以相同业务契约对比框架差异。实验室用于对比控件库和图表库，不作为生产业务页面的混合依赖。

## 工程与页面要求

- React、Vue、Angular 各自拥有完整独立项目，可脱离父仓库安装、运行和构建。
- 每端实现相同一级路由、主题策略、权限语义、Mock 适配、Dashboard 和核心设备流。
- 主 UI：React/MUI、Vue/Element Plus、Angular/Angular Material。
- UI 实验室：分别展示各框架 Top 3 热门组件库的表格、表单、弹窗、导航和主题能力。
- 图表实验室：用相同数据集分别实现 ECharts、Chart.js、D3.js 的趋势、柱状、饼图和性能/体积说明。

## 业务规则

- 三端遵循统一领域、Mock 确定性规则和设计规范；领域类型、Mock API、设计令牌、组件、状态、资源、依赖和测试均各自维护，不共享运行时代码。
- 一个业务页面只加载一个主 UI 库；实验室页面必须隔离样式作用域和依赖说明。
- 任一框架故障不得阻塞其他框架启动和测试。

## 验收条件

- Given 相同 seed、租户和时间范围，When 在三端查询大盘，Then 关键业务值一致。
- Given 打开组件实验室，When 切换库示例，Then 不影响业务大盘的样式或功能。
- Given 任一应用执行构建，When 其他应用未安装或失败，Then 该应用仍可独立构建。

## 2026-09-20 主 UI 示例增量

三端各自建立 `/labs` 路由，用本端现有主 UI 库展示固定的三台演示设备。页面提供表格筛选、表单校验、对话框、示例导航、局部明暗主题与重置操作；页面注明其他组件库、图表库、统一条件下的体积和性能测量尚未实现。局部主题不修改业务页面的主题设置。该增量不构成 Top 3 或完整实验室验收。

## 2026-09-20 三库图表同数据增量

三端各自安装 Chart.js 与 D3.js，并复用各端已有 ECharts，独立实现同一固定四时点消息数据的趋势、柱状、饼图。用户可在本端实验室切换库与图形；图表包按选择动态加载，原始数值在图表旁可读，示例失败可恢复默认图表。此增量仍缺 Top 3 UI 组件库示例、统一条件下的体积与性能测量、源代码入口及 REVIEW-004 结论，不能视为完整实验室验收。

## 2026-09-20 实现源码入口增量

三端各自的构建命令将本端实验室 UI、图表界面和渲染适配源码复制到本端静态资源目录。实验室“查看实现”链接直接访问这些本端源码，关联 PRD 链接访问本端随附的需求快照并标明中央规范路径；源码副本在构建时刷新，不依赖父目录资源。React/Vue 的 Top 3 候选原型已接入；Angular 候选原型已接入，但 PrimeNG 许可与 REVIEW-004 正式选型、统一测量和最终验收仍待完成。

## 2026-09-20 React/Vue UI 候选库原型增量

React 实验室可切换 MUI、Ant Design、Chakra UI；Vue 实验室可切换 Element Plus、Vuetify、PrimeVue，使用本端固定 seed 展示表格、表单、对话框、导航和局部主题。Vue 的两个候选在同端独立 iframe 入口运行，以隔离 Vuetify 全局样式；候选代码仍由 Vue 本端独立维护。PrimeVue 5 需要许可证密钥，本端采用 MIT 许可的 4.5.5 作为可运行原型，最终版本与选型仍待 REVIEW-004。Angular 已接入 ng-bootstrap 与 NG-ZORRO 替代原型；PrimeNG 许可、正式 Top 3 选型、统一体积/性能测量与最终验收尚未完成。

## 2026-09-20 Angular UI 候选原型增量

Angular 实验室可在 Angular Material、ng-bootstrap 与 NG-ZORRO 替代原型之间切换。后两者运行在本端懒加载 iframe 路由，用同一固定 seed 展示表格、表单、弹窗、导航与局部主题；候选 CSS 不进入业务页面。ng-bootstrap 表格是 Bootstrap 表格样式加其分页控件，而非独立表格组件。按下载量排名第二的 PrimeNG 22 随包要求许可证密钥，当前仓库未获密钥，故未安装；最终 Top 3 选型待 REVIEW-004。

## 2026-09-20 本机性能与体积采样增量

三端各自提供 `npm run measure:labs`，对生产构建中的三个 UI 场景与三种图表库场景在本机 Chromium 下采样三次，报告采集时间、计时起点、实际请求的 JS/CSS 原始及 gzip 估算字节数。各端实验室提供本端 HTML 报告及原始 JSON 入口。默认页加载与随后切换的计时口径不同；结果用于观察当前实现与构建，不能视为单库包大小或线上性能结论。统一硬件基准、进一步的资源优化、人工视觉审核与 REVIEW-004 仍待完成。

## 2026-09-20 React/Vue 候选按库加载增量

React 的 Ant Design 和 Chakra UI 各有独立懒加载模块，默认 MUI 示例不请求候选模块。Vue 的 Vuetify 和 PrimeVue 各有独立 iframe HTML 入口、应用初始化和组件文件，仅所选入口加载对应库脚本；Vuetify 样式继续留在自身 iframe。两个候选均维持固定 seed、表格/表单/弹窗/导航、局部主题和本端源码链接。三端实验室最终选型及视觉审核仍待 REVIEW-004。

## 2026-09-20 Angular 候选按库加载增量

Angular 的 ng-bootstrap 与 NG-ZORRO 分别使用本端独立懒加载路由、组件和模板，iframe 只进入所选候选路由并装入对应样式。两个示例继续使用同一固定数据、相同交互和本端源码链接。PrimeNG 许可证与正式 Top 3 选型仍待 REVIEW-004。

## 页面结构

平台管理员进入租户列表，可按状态、套餐和用量筛选。租户详情包括概览、成员、角色、配额、产品和设备页签。顶部始终显示当前租户上下文与配额健康状态。

## 用户流

1. 创建或编辑租户：输入名称、状态、套餐与配额 → 预览资源上限 → 保存。
2. 管理成员：点击添加成员 → 选择 Mock 用户和角色 → 预览权限 → 确认；角色变更和移除均显示影响。
3. 管理配额：调整软预警和硬上限 → 查看受影响资源 → 提交；超限时跳转到资源清理入口。

## 交互规则

- 当前租户切换为全局上下文，切换前如存在未保存数据须确认。
- 角色权限预览为只读矩阵，避免用户通过隐藏按钮猜测权限。
- 配额使用率分为正常、预警、超限；超限操作同时显示已用值、上限和解决路径。
- 移除最后一个租户管理员必须阻止并解释必须保留至少一名管理员。

## 异常与可访问性

跨租户资源请求显示无权限而不展示资源名称。表格、权限矩阵和配额图均提供屏幕阅读器摘要。

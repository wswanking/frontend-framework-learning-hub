## 页面结构

实验室使用“框架选择 → UI 库 / 图表库 → 示例 → 对比信息”层级。每个示例页包含同一业务数据的可交互组件、实现说明、依赖、可访问性注意事项、构建体积和适用场景。

## 用户流

1. 选择 React、Vue 或 Angular；默认进入该框架主 UI 库。
2. 在 UI 库间切换，比较表格、表单、弹窗、导航、主题和数据密集控件。
3. 在图表库间切换，使用同一时序/分类数据观察 ECharts、Chart.js、D3.js 的差异。
4. 点击“查看实现”进入该框架对应源代码和关联 PRD，而非跨框架复制粘贴代码。
   本端源码由各应用构建时生成静态只读副本；链接包含 UI 页面、各候选库实现、图表界面和渲染适配。React 候选按所选库懒加载；Vue 的两个候选分别运行在本端独立 iframe 入口，Angular 的两个候选分别运行在本端懒加载 iframe 路由，候选 UI 样式不进入业务页面。PRD 链接为本端随附快照，页面标明中央规范路径。

## 交互规则

- 切换库不改变当前演示数据 seed；任何体积/性能数据标注采集日期和构建条件。
- 示例可修改局部参数，但重置后回到默认场景。
- 实验室主题与主应用主题独立隔离，禁止污染业务页面。
- 图表库与类型切换使用同一固定数据；趋势、柱状、饼图旁保留可读原始数值，示例异常提供恢复默认图表操作。

## 验收

用户能在同一数据与同一任务下比较三框架和三类库；任一示例异常只影响自身并给出恢复操作。

## 页面结构与层级

```text
筛选栏：租户 / 产品 / 状态 / 地域 / 时间
面包屑：全球 > 洲 > 国家 > 节点
主体：地图画布 + 缩放 / 定位 / 图例
右侧：选中对象详情抽屉
底部：未定位设备与列表替代视图
```

## 用户流

1. 默认展示全球聚合点和洲级统计。
2. 点击区域/聚合点，更新面包屑并进入下一层；返回通过面包屑完成。
3. 点击节点或设备点，打开详情抽屉；抽屉可跳转到设备详情。
4. 用户切换“列表视图”，保留全部筛选与层级上下文。

## 交互规则

- 鼠标滚轮/双指缩放只改变地图层级，不自动改变筛选范围。
- 地图点密集时展示聚合数量，放大后拆分；图例可筛选在线、离线、故障。
- 未定位设备不绘制伪坐标，统一进入列表；点击可进入详情但不显示地图定位。
- 抽屉关闭不清除当前地图层级；点击空白区域只取消选中对象。

## 异常与可访问性

地图不可用时自动显示同数据的可排序列表。所有地图选择都有键盘可达的列表替代入口，详情抽屉包含对象名称和层级说明。

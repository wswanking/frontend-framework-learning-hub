## 页面结构与层级

```text
筛选栏：租户 / 产品 / 状态 / 地域 / 时间
面包屑：全球 > 洲 > 国家 > 节点
主体：地图画布 + 缩放 / 定位 / 图例
右侧：选中对象详情抽屉
底部：未定位设备与列表替代视图
```

## 用户流

1. 默认展示全球聚合点和洲级统计。
2. 点击区域/聚合点，更新面包屑并进入下一层；返回通过面包屑完成。
3. 点击节点或设备点，打开详情抽屉；抽屉可跳转到设备详情。
4. 用户切换“列表视图”，保留全部筛选与层级上下文。
5. 从大盘洲、国家或节点入口进入时，恢复租户、精确 UTC 时间窗与目标层级面包屑；用户可改选时间范围并重新应用筛选。

## 交互规则

- 鼠标滚轮/双指缩放只改变地图层级，不自动改变筛选范围。
- 地图右上角提供放大、缩小和“全球”视角复位按钮；键盘可以操作，视角限制为 1–8 倍，复位后回到全球中心。
- 地图点密集时展示聚合数量，放大后拆分；图例可筛选在线、离线、故障。
- 状态图例还包含未激活、维护和告警；选择图例会立即更新同一状态查询，因此地图、列表、未定位设备与统计同步变化，并保留当前地理层级。混合状态聚合点显示中性色。
- 设备层聚合点点击后以该点为中心放大；达到最大倍数仍重合的设备可从旁侧列表分别访问。聚合不改变列表和统计。
- 未定位设备不绘制伪坐标，统一进入列表；点击可进入详情但不显示地图定位。
- 抽屉关闭不清除当前地图层级；点击空白区域只取消选中对象。

## 异常与可访问性

地图不可用时自动显示同数据的可排序、分页列表，每页 10 项；切换层级或应用筛选时返回第一页。所有地图选择都有键盘可达的列表替代入口，设备详情抽屉可直达设备详情页。

## 同一业务契约

精确种子与字段读取 `交互/index.html`，不可自行改名/改变基本值。ColdSense T200 温控主线、EnergyLink M1 电表仅能耗规格/元数据，不显示温控操作。

- 注册唯一序列号→待接入→模拟上报变在线、追加时序/日志；搜索草稿应用后进入 URL；CSV 只读已应用查询；批量删除需 DELETE。
- 温度阈值规则→模拟输入触发待确认告警→负责人/说明确认→原因解决→审计。
- OTA 仅选在线兼容温控目标；待执行→运行→部分失败（最后一台）→填写原因仅重试失败项→完成；成功尝试次数保持1、失败重试2。活跃 OTA 目标禁止删除；重试/推进检查存在及在线。
- 仅平台管理员治理邀请/角色/配额；配额不得低于实际设备数。平台/租户管理员创建及编辑设备/规则/OTA；运维可上报、命令、告警、规则试运行、OTA推进重试；观察员全部写入拒绝。必须在领域命令校验权限、输入和状态，失败不留下部分修改或审计。
- 产品属性查看/新增，设备影子/同步/重启/日志、节点详情、连接模拟测试、审计过滤、设置通知偏好、搜索/通知跳转均按覆盖矩阵可操作；连接不访问外部服务、邀请不发邮件、无真实硬件控制。

## 页面结构

产品列表提供搜索、筛选、创建和批量操作。产品详情使用“基础信息 / 接入配置 / 物模型 / DP 规则 / 设备”页签。编辑页右侧保留校验摘要和未保存变更提示。

“设备”页签按当前产品与租户列出关联设备、总数和分页；设备名称链接到本端设备详情。无关联设备时展示空状态，查询失败时显示错误及重试。

## 用户流

1. 创建产品：填写基础信息 → 选择接入协议 → 保存草稿 → 配置物模型。
2. 新增物模型项：选择属性/事件/服务 → 填写标识、名称、类型与约束 → 预览 JSON → 保存。
3. 配置 DP：选物模型项 → 输入映射、单位、倍率、偏移和阈值 → 输入样例原始值 → 查看逐步转换结果 → 保存。
4. 修改已有模型：系统展示关联设备、规则与 OTA 的影响；用户确认后才允许提交关键变更。

## 控件与校验

- 标识实时校验字符、长度和同产品唯一性；异步冲突提示不阻塞继续编辑。
- 数据类型切换时，保留兼容字段；不兼容字段标记将被清除，需用户确认。
- 表单/JSON 双视图为同一草稿；JSON 不合法时禁止切回表单并定位错误行。
- DP 试运行区展示原始值、各转换步骤、最终值、范围校验和错误位置。

## 状态与权限

租户管理员可编辑；运维和观察员进入只读模式。离开未保存页面时显示保存、放弃、取消三选项。删除关键项进入影响确认弹窗。

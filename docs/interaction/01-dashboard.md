## 页面结构

```text
上下文栏：租户 | 时间范围 | 地域 | 主题
标题区：全球设备运行态势 | 最后更新时间 | 刷新
指标区：设备 / 在线率 / 消息 / 告警 / OTA
分析区：地图 + 地域/国家排行 | 消息趋势 + 告警分布
事件区：实时事件流 | 查看全部
```

## 用户流

1. 用户选择租户、时间或地域，点击“应用”或使用预设时间。
2. 页面显示局部加载，筛选结果返回后同时更新指标、地图、排行和图表。
3. 用户点击地图或排行项，打开摘要抽屉；点击“查看设备/节点”进入下钻页。
4. 用户切换主题，立即生效并在刷新后保留。

## 控件规则

- 时间预设默认 24 小时；自定义范围不能晚于当前时间，开始时间必须早于结束时间。
- 筛选草稿只有在“应用”后影响大盘；“重置”回到租户默认范围。
- 指标卡点击仅在存在明确下钻目标时呈现链接样式。
- 实时事件默认自动追加；用户滚动查看历史时显示“有 N 条新事件”，点击后回到顶部。

## 状态与反馈

地图失败不阻塞指标；卡片无数据展示 `—` 并解释筛选范围内无设备。筛选失败时保留上一次成功数据并标记为“非最新”，提供重试。

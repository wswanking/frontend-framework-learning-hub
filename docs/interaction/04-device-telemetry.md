## 页面结构

设备列表包括筛选抽屉、结果表格、批量操作栏和列设置。设备详情包括概览、实时属性、设备影子、时序数据、消息、告警、位置、规则执行、OTA 历史页签；右侧显示在线状态和快捷操作。设备影子并列显示已上报属性和待执行命令的期望值，命令模拟完成后更新。

## 用户流

1. 用户按产品、状态、地域、标签或关键词筛选设备；表格更新总数与分页。
2. 点击设备进入详情，默认显示概览和关键属性。
3. 在时序页选择指标和时间范围，系统加载图表；选择采样粒度或缩放会刷新同一查询。
4. 运维工程师发起控制：填写物模型表单 → 预览命令 → 提交 → 在命令记录查看等待、成功或失败。

控制预览从设备详情右侧展开，显示目标设备、参数及权限和在线状态；确认与取消按钮保持可见。窄屏时预览使用全屏宽度。

控制预览打开后焦点进入面板，Tab 在操作按钮间循环；Escape 与取消返回“预览命令”。发送成功后焦点进入命令记录页签。

服务拒绝命令时在控制预览面板内显示原因；用户取消、修改参数并重新预览时清除旧错误。

新建设备、CSV 导入和批量删除确认弹窗打开时将焦点移入弹窗；Tab 与 Shift+Tab 在可用控件内循环，Escape 取消并回焦触发按钮。

这些弹窗打开期间页面背景不能随滚轮滚动，关闭后恢复原滚动能力。

右侧控制预览面板打开期间同样锁定背景页面滚动；取消或发送后恢复。

## 交互规则

- 筛选条件显示为可移除标签；重置只清除本页筛选。
- 实时属性显示最后更新时间；超过离线阈值时显示“数据可能过期”。
- 图表缩放后出现“恢复全范围”；选中多指标时以单位分组或提示不可同轴比较。
- 自定义时序范围使用 UTC 起止分钟，结束时间须晚于开始时间且跨度不超过 30 天；无效输入保留在表单并说明原因。
- 设备影子仅在命令待执行时显示期望值和命令 ID；命令失败不修改已上报值。影子为本端 Mock，需与命令记录的状态一致。
- 时序页实时追加的有效点更新影子已上报值；缺失点和旧时间点不得覆盖较新值。退出订阅后影子保持最后一次已保存值。
- 控制按钮在无权限或设备离线时禁用，并展示原因；不允许通过禁用按钮触发提交。

## 异常与可访问性

时序无数据展示缺失时间范围与调整入口；表格支持键盘排序与分页；图表提供可复制的数值摘要表。

## M2 列表与编辑返回（2026-10-18）

已应用筛选、排序、每页数量与页码随 URL 恢复，输入草稿仅在“查询”时应用；详情 ID 追加在同一查询上。关闭详情不重置筛选或分页。正常回焦原设备按钮，刷新深链接后回焦列表标题。

列表失败不同时显示“没有设备”；详情错误在抽屉中显示原因与“重试详情”。保存失败保留输入，“重试保存”重新提交当前草稿；“重新加载设备”需明确确认丢弃草稿，适用于版本冲突。保存成功反馈在详情中，列表查询刷新不吞掉该反馈。只读角色说明无编辑权限。

64rem（默认 1024px）及以下、占满视口的详情锁定背景滚动并将 Tab/Shift+Tab 保持在可用详情控件内；嵌套控制/登记弹窗沿用自身焦点管理，已被内层处理的 Escape 不再关闭外层详情；历史离开时释放全部滚动锁。Escape 经脏状态确认后关闭详情并恢复焦点。

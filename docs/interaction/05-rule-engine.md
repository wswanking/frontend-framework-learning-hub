## 页面结构

规则列表展示启用状态、产品、版本、最近执行和成功率。编辑页由节点面板、画布、节点属性面板、校验摘要和试运行面板组成；日志页以可筛选表格呈现。

## 用户流

1. 创建规则：选产品和触发器 → 拖入条件/转换/动作节点 → 连线 → 配置节点 → 校验 → 保存草稿。
2. 试运行：选择样例报文 → 执行 → 查看画布节点状态与逐节点输入/输出 → 保存为测试样例（可选）。
3. 发布/启停：展示影响设备数与当前版本；确认后变更状态。

## 交互规则

- 连线只能从兼容输出到输入；不兼容端口不可放置并显示原因。
- 保存前检查触发器、动作、未配置字段、孤立节点和循环；错误点击可定位到节点。
- 试运行不改变设备数据；“应用模拟结果”需单独确认并写入演示日志。
- 节点执行用成功、跳过、失败、等待状态区分，并提供文本说明。

## 异常与权限

表达式超时、字段缺失、动作失败显示在节点和日志两个位置。租户管理员可编辑启停，运维可试运行，观察员只读。

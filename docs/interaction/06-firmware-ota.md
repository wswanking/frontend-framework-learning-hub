## 固件交互

固件列表支持产品、状态和版本搜索。新建采用三步流程：选择文件 → 读取/确认元数据与校验 → 选择适配产品并提交。详情展示版本、校验、引用任务和归档操作。

文件读取中显示进度；校验失败、重复版本和不兼容产品在同屏说明。被任务引用的固件删除操作禁用，并链接到引用任务。

## OTA 创建与监控

```text
选择固件 → 选择目标设备 → 配置灰度/阈值 → 影响预览 → 确认创建
```

任务详情顶部显示状态、进度、批次和失败率；中部展示进度趋势与状态分布；底部设备明细支持按状态和失败原因筛选。暂停、继续、取消、重试和回滚均使用确认弹窗，弹窗明确设备数量和影响。

## 状态与反馈

- 状态机：草稿、等待、下载、校验、安装、重启、成功、失败、已暂停、已取消、回滚中、已回滚。
- 失败率超过阈值时自动暂停，显示“需人工确认后继续”的横幅。
- 单台设备升级进度通过实时事件更新；失去事件连接时标记数据过期并可重连。
- 回滚不会删除原始升级历史，而是打开新的回滚记录。

## 权限与验收映射

租户管理员创建/取消，运维暂停/重试，观察员只读。覆盖固件有效性、灰度阈值自动暂停、重试历史和回滚不可变性验收条件。
